# Urban Wholesalers Properties LTD

Company website for Urban Wholesalers Properties LTD, a UK property company developing an Android rental-management app for landlords.

**Live site:** https://milan6354.github.io/urban-wholesalers-website/

## About this repository

A static one-page website: plain HTML, CSS and a little JavaScript. No build step, no cookies, no tracking and no backend.

- `index.html`: the page
- `assets/`: styles, script, self-hosted fonts and images
- `404.html`: page-not-found page

App screenshots show fictional sample data. The app is in development and isn't on Google Play yet.
